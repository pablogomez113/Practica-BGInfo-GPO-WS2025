# Práctica BGInfo y GPO en Windows Server 2025

## Descripción
Documentación de una práctica de administración de sistemas en la que se configura BGInfo para mostrar información del equipo en el escritorio de los usuarios mediante una directiva de grupo (GPO).

## Objetivo
Configurar BGInfo en Windows Server 2025, preparar los archivos necesarios, permitir el acceso de los usuarios del dominio y ejecutar la aplicación durante el inicio de sesión mediante un script `.bat`.

## Tecnologías y herramientas
- Windows Server 2025
- BGInfo
- Directivas de grupo (GPO)
- Script por lotes (`.bat`)
- Active Directory / grupo Domain Users

## Alcance
La documentación recoge la preparación de BGInfo, la configuración del fondo, el uso compartido de la carpeta, los permisos para Domain Users, la creación del script `BGInfo.bat`, su incorporación a la configuración de inicio de sesión y la prueba con el usuario `usu1`.
